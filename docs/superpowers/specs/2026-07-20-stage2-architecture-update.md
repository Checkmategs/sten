# Sten — обновление архитектуры после этапа 1

Дата: 2026-07-20
Статус: согласовано по ходу (этап 1 пройден на GPU-сервере)

## Изменения относительно исходной спеки

Этап 1 показал: на MacBook 16 ГБ качество и скорость ограничены. Обработка перенесена на офисный сервер:

- Хост: `nineone@10.91.0.142` (Linux, 4× NVIDIA RTX A4000 16 ГБ, 251 ГБ RAM)
- ASR: `faster-whisper` `large-v3`, `float16`, CUDA
- LLM: Ollama `qwen2.5:32b-instruct` (качество саммари заметно выше 7B; модели крутятся через env без смены кода)
- MacBook: запись микрофона в браузере, UI согласования на ТВ (AirPlay/HDMI), опционально локальный пайплайн для разработки

On-prem сохранён: данные не уходят в публичные облака, только LAN.

# Обзор совещания не должен ждать рассуждения модели

Контекст. Модель из `STEN_OLLAMA_MODEL` (`qwen3.8-27b`) по умолчанию пишет длинный скрытый ход рассуждений. `sten/llm.py` вызывал `/api/generate` без `think: false`, поэтому один шаг обзора декодировал больше 10 тысяч служебных токенов (~20 ток/с) и обрывался по таймауту 600 с. Транскрипт при этом уже был готов.

Решение. Все вызовы Ollama в `sten/llm.py` передают `think: false`. В `sten/report.py` длина ответа ограничена: выжимка фрагмента — `_MAP_PREDICT` (1536 токена), итоговый JSON обзора — `_REPORT_PREDICT` (4096). На транскрипте около 21 тысячи символов обзор собирается четырьмя вызовами примерно за три минуты.

Затронуто: `sten/llm.py`, `sten/report.py`, шаг «Обзор совещания…» в пайплайне и `POST /api/meetings/{id}/resummarize`.

Последствие. Обзор успевает завершиться в таймаут. Если модель без режима рассуждений получит `think: false`, Ollama это поле игнорирует.
